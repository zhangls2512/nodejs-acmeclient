基于Nodejs的ACME客户端，可用于无状态运行的云函数。  
**一、简介**  
1.可用于无状态运行的云函数，传递输入参数即可运行，运行结束后无数据残留。  
2.请严格按照文档中的要求传递输入参数。  
**二、文件**  
doc/：文档  
src/：源码  
CHANGELOG.md：更新日志  
**三、功能**  
api：ACME  
crypto：密钥、CSR、证书  
verify：验证挑战  
**四、输入、输出参数**  
`string` 说明  
输入参数以`(输入参数)`形式传递。  
输出参数为`string`类型，如`'success'`。
|名|类型|必需|说明|
|---|---|---|---|
|a|string|是|xxx|
|b|number|否|xxx|

输入参数以`({a:输入参数a,b:输入参数b})`形式传递。  
输出参数格式如`({a:输出参数a,b:输出参数b})`，示例：`{a:'测试',b:0}`。
